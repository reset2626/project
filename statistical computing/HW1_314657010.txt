                       一、研究動機（Introduction）
                       在課堂中，我們以擲硬幣作為基本的隨機實驗範例，每次實驗只有兩種可能結果。為了延
                       伸此概念，本研究將擲硬幣的模型應用於簡單的金融情境，模擬股票價格的隨機變動。

                       在此模型中，股票價格每天可能上升或下降，類似於硬幣的正反面結果。本研究利用均勻
                       分布的隨機數來決定每日的漲跌方向，並透過電腦模擬多條價格路徑，觀察其統計特性。

                       此外，本研究亦比較兩種不同的隨機數產生器——線性同餘產生器與 PCG——探討不同
                       RNG 對模擬結果的影響。

                       # LCG

                       class LCG:
                           def __init__(self, seed=1, a=1664525, c=1013904223, m=2**32):
                               self.state = seed
                               self.a = a
                               self.c = c
                               self.m = m

                             def random(self):
                                 self.state = (self.a * self.state + self.c) % self.m
                                 return self.state / self.m

             In [2]: def simulate_stock_path(n_days, s0, rng_func):

                       六、討論（Discussion）
                       由於模型簡單且樣本數足夠大，LCG 與 PCG 的結果差異不明顯。然而，PCG 在理論上具

                       七、未來研究方向（Future Work）
                       本研究採用簡單的隨機漫步模型與均勻隨機數產生器進行模擬，未來可從以下幾個方向進
                       一步延伸：

                          1. 非對稱機率模型
                             本研究假設股價上漲與下跌機率相同（0.5），未來可考慮不對稱機率，以模擬多頭
                             或空頭市場情境。

                          2. 報酬分布的擴展
                             將每日價格變動由固定的 ±1 改為隨機報酬，例如常態分布或其他分布，使模型更接
                             近實際金融市場。

                          3. 更真實的金融模型
                             可進一步採用幾何布朗運動（Geometric Brownian Motion）或其他隨機微分方程模
                             型，模擬連續時間的價格變動。

                          4. 隨機數產生器品質分析
                             本研究僅比較 LCG 與 PCG，未來可納入更多 RNG（如 Mersenne Twister），並透
                             過統計檢定（如自相關、uniformity test）進行系統性比較。

                          5. 風險衡量指標的擴展
                             除了平均值與機率外，可進一步計算金融風險指標，例如 Value at Risk（VaR）與
                             Expected Shortfall，以更完整描述投資風險。

                          6. 模擬次數與收斂性分析
                             可研究隨著模擬次數增加，統計量（如平均值）如何收斂，並比較不同 RNG 在收斂
                             速度上的差異。

                          7. 多資產或多變數模型
                             未來可擴展至多支股票或相關資產的模擬，研究資產間相關性對投資組合的影響。
