結合卡爾曼濾波器與類神經網路的時間序列預測方法
學生：林裕倫 指導教授：高竹嵐 博士
國立陽明交通大學 統計研究所
摘 要
從金融市場對於價格的預測到天氣溫差的變化，這些都脫離不了時間序列模型，傳
統的 ARIMA 模型雖然在穩定的線性資料下具有高預測能力和解釋力，但對於非線性資
料如氣溫或天氣的預測卻存在局限性。為了克服這些挑戰，我們找到了 ARIMA-ANN
混合式的時間序列模型，是將傳統的時間序列模型與人工神經網絡（ ANN）結合，而
本文引入了卡爾曼濾波器以提升模型性能。
此外，我們提出了一種針對時間序列資料的 bootstrap 方法，使得 ANN 能成功進行
區間預測。通過這種結合，我們的模型不僅能捕捉非線性關係和動態變化，還能提供
更準確和穩健的預測結果。我們使用模擬的時間序列資料驗證了 bootstrap 方法的有效
性，並在實務面上使用太陽黑子和台灣股市的資料進行測試。結果顯示，我們的模型
在一步預測的情況下，其均方差表現與 Babu 所提出的模型相當，並在某些情況下有超
越之處。
這種創新方法展示了混合模型在複雜時間序列預測中的潛力，為金融市場等領域的
實際應用提供了有力支持。
關鍵詞: 時間序列模型, 混合式模型, 卡爾曼濾波器、ARIMA、ANN、bootstrap

A Time Series Forecasting Method Combining Kalman Filter
and Artificial Neural Networks
Student: Lin, Y u-Lun Advisor: Dr. Kao, Chu-Lan
Institute of Statistics
National Y ang Ming Chiao Tung University
Abstract
From forecasting prices in financial markets to predicting temperature variations, time series
models are indispensable. While traditional ARIMA models excel in forecasting stable linear
data due to their high predictive power and interpretability, they fall short when dealing with
nonlinear data such as temperatures or weather patterns. To overcome these challenges, we
have developed a hybrid ARIMA-ANN time series model, combining traditional time series
models with Artificial Neural Networks (ANN). Additionally, this paper introduces a Kalman
filter to enhance model performance.
Furthermore, we propose a bootstrap method for time series data, enabling ANN to success-
fully perform interval forecasting. This hybrid approach allows our model to capture nonlinear
relationships and dynamic changes, providing more accurate and robust predictions. We val-
idate the effectiveness of the bootstrap method using simulated time series data and conduct
practical tests using sunspot and Taiwan stock market data. The results demonstrate that our
model’s mean squared error in one-step-ahead forecasting is comparable to Babu’s model and
even surpasses it in some cases.
This innovative method showcases the potential of hybrid models in complex time series
forecasting, offering strong support for practical applications in financial markets and other
fields.
Keywords: time series model, hybrid model, Kalman filter, ARIMA, ANN, bootstrap

一、 緒論
1.1 研究動機與目的
台灣人對投資的熱情有目共睹，無論是股票市場、房地產、基金，還是近年來興起
的數位貨幣，人們總能在各種投資領域中找到機會並積極參與，甚至在 2024 年 3 月台
股達到了兩萬點的高峰，在論文題目的選擇中，我們也能看到許多關於投資的論文，
但其實無論是哪一種的金融商品，都免不了要需要對價格進行預測，這些主題最根本
的核心基本上都是對著時間序列資料建模，也就是本論文想要研究的主題，能不能找
到一個更好的時間序列模型來預測資料呢?
時間序列一直都是熱門的研究領域，但我們對於時間序列模型的架構卻還是倚賴
ARIMA 之類的傳統模型，很多時候過度複雜的資料預測會失準，更甚至一些高波動、
不穩定的資料本就不適合 ARIMA 模型，像是氣溫或是天氣之類的資料，時常需要機
器學習的模型去幫助預測，但在穩定的線性資料下， ARIMA 也有非常高的價值，不僅
僅是預測能力，模型的解釋力也非常的高，不過完全符合 ARIMA 模型假設的資料也
不多，於是我就在思考能不能將兩種模型的優點結合起來，剛好發現了 Babu 的論文 A
moving-average filter based hybrid ARIMA–ANN model for forecasting time series data[ 1]，
也是將傳統的時間序列模型與 ANN 模型結合，去實現對於時間序列資料的預測，本篇
的論文也是基於此想法下去改進，最後的結果也超越了 Babu[1] 提出的模型，且提出了
一種對於時間序列資料的新的 bootstrap 方法，增加了預測區間的部分，使得預測不再
僅僅只是點估計。
本文將會用一組模擬的時間序列資料來驗證 bootstrap 方法的有效性，實務面則使用
太陽黑子與台灣股市的資料來與 Babu[1] 提出的模型比較，最後得到的結果是在一步預
測的情況下，我們的模型均方差是不輸他的模型的。

2.3 ARIMA-ANN
ARIMA–ANN model 最 早 是 由 Zhang 在 [3] Time series forecasting using a hybrid
ARIMA and neural network model 這 篇 論 文 提 出 的， 主 要 的 想 法 是 假 設 時 間 序 列 資
料可以分成線性與非線性的兩個部分，用 ARIMA 去預測低波動的部分，而剩下的部
分交由 ANN 去處理，具體來說就是將資料先用 ARIMA 建模，再將此模型的殘差交給
ANN 去做預測，最後的預測值就是將 ARIMA 的預測值加上 ANN 的預測值，在此論
文中，此模型在一步預測和多步預測都優於單獨的 ARIMA 模型或 ANN 模型；之後
khashei 在 [4]A novel hybridization of artificial neural networks and ARIMA models for time
series forecasting 這篇論文提出了另一個 ARIMA-ANN 的模型，此模型是先將資料用
ARIMA 模型擬合，並且進行預測，最後將原始資料、 ARIMA 預測的資料以及誤差序
列值都當作 ANN 的輸入，而最終 ANN 的輸出即為最終的預測值，在預測以及精度
來說，此方法也比 Zhang 提出的模型有更好的性能；而 Babu 也在 [1]A moving-average
filter based hybrid ARIMA–ANN model for forecasting time series data 提出了先用 MA 濾
波器將資料分成低波動和高波動的部分，再分別用 ARIMA 跟 ANN 進行建模，MA 濾
波器的想法是將資料取移動平均 (moving-average)，將此資料當作平穩資料，移動平均
還需要一個長度 m，m 的取法是看平穩資料達到峰態 (Kurtosis) 等於 3；原始資料與平
穩資料相減則是不平穩資料，也就是先前提到低波動和高波動的部分， Babu 也比較了
Zhang 和 khashei 的方法，結果顯示 Babu 的方法會比其他兩個模型有更好的精度。
2.4 bootstrap
2.4.1 bootstrap
bootstrap 是由 Bradley Efron 所提出的，在 An introduction to the bootstrap [ 5] 中有完
整對於 bootstrap 的介紹，主要的想法是對樣本抽出放回的方式去抽樣，做出足以代表
母體的分布，進而更準確的去描述母體；當時主要是對參數估計和統計量去做信賴區
間，後面則推廣到可以去造預測值的信賴區間。

2.4.2 block bootstrap
Carlstein 在 The use of subseries values for estimating the variance of a general statistic
from a stationary sequence [ 6] 中提出了 block bootstrap 的概念，將資料切成 b 個不重疊的
blocks，再對這些 blocks 進行抽出放回的抽樣；這方法在一定程度上解決了 bootstrap 無
法處理時間序列資料的問題，但如果資料背後有很強的結構， block bootstrap 也沒辦法
模擬，我們將會在後面的 3.2.1討論。
2.5 卡爾曼濾波器 (Kalman filter)
Greg Welch 和 Gary Bishop 在 An introduction to the Kalman filter[ 7] 一文中詳細介紹
了 Kalman filter 的歷史及用法，當資料有噪音時，卡爾曼濾波器可以很好的去過濾掉噪
音，並估計出當時的狀態，現在也被運用在一些時間序列當中，此模型的想法是將觀
測值和過去的狀態去預測現在的狀態，狀態值 x ∈ R n 和觀測值 z ∈ R m 如下兩式所示:
xk+1 = Akxk + Buk + wk (2.4)
zk = Hkxk + vk (2.5)
其中，n × n 的矩陣 A 為在 k 到 k + 1 時的狀態相關矩陣，而 n × l 的矩陣 B 則為與控

3.2 bootstrap
在做研究的同時，我們同時遇到了想要製造預測區間的問題，使用的方法是用
bootstrap 去生成假資料並做預測，使得有更多的預測值，再將其取分位數的預測區
間，但由於我們的資料為時間序列資料，如果使用傳統的 bootstrap 的話，會導致時間
結構消失，為此我們嘗試了許多方法，並找出了一種可以保留時間結構的 bootstrap，
在 2.4已經簡單介紹 bootstrap 與 block bootstrap 是如何操作的，接下來將會討論我們所
提出的 bootstrap 方法。
3.2.1 sort bootstrap
sort bootstrap 是我們新提出的方法，想法是將 bootstrap 用原本資料的順序排序，以
保留原本資料的序列結構，具體的步驟如下:
Step 1: 將原本的資料先做編號；假如有十筆資料，將每一筆資料都標上編號 1 到 10。
Step 2: 將原本的資料進行 bootstrap 並排序；假如資料 bootstrap 的結果為 [1,5,2,2,3,7,3,6,9,8]，
則排序過後為 [1,2,2,3,3,5,6,7,8,9]，要特別注意的是，這並不是照著大小排序，
而是照著原本資料的順序排序。
Step 3: 重複”Step 2” n 次即為我們的 bootstrap 樣本。
此方法的一階動差與二階動差皆與 bootstrap 一致，排序並不影響樣本內的一二階動
差，更重要的是樣本外的表現，我們使用了一些簡單的時間序列資料來驗證我們的方
法是否有效，以下以 AR(1) ϕ = 0.8 的情況舉例:

六、 未來研究方向與結論
本文雖然是使用卡爾曼濾波器將資料分成高波動和低波動的部分，但並未使用古典
的波動性模型 (ex.GARCH) 進行比較，其中的原因為波動性模型基本上著重於資料的變
異數或二階動差，但我們進行的比較為與原始資料的均方差，用波動性模型會較不合
適，相反的，如果認為資料具有某種 ARIMA 以外的模型特徵，我認為將 ARIMA 變成
其他的線性模型也會有不錯的效果。
本文在 3.2.1所提供的 sort bootstrap 方法，在模擬的數據上是可行的，但我們目前還
不能在數學上證明此方法是有效，在 Forecasting nonlinear time series with neural network
sieve bootstrap[8] 這篇文章中，也有提出一種時間序列的 bootstrap 的方法，比較兩種
bootstrap 的方法或許可以是一個研究方向。
類神經網路與卡爾曼濾波器都有許多的調整空間，類神經網路的部分從神經元、隱
藏層、激活函數這些模型設置的部分，到學習率、epochs、權重衰減等超參數調整，而
卡爾曼濾波器則有隱藏狀態和初始值設定的問題，這些基本上都有討論與改進的空間，
但我認為模型整體的架構才是重點，我們的模型很好的結合了 ARIMA 和 ANN 的優
點，且在預測數據的表現皆不輸 Babu[1] 提出的模型，且我們的模型假設十分寬鬆，基
本上可以應用在各種時間序列的資料上，因此本文提供了一個應用廣泛且簡單準確的
時間序列模型。
